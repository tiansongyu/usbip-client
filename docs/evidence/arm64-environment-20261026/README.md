# ARM64 environment checkpoint

Originals retain both successful product-free preparations, image signatures/hashes, actual architecture and module outputs, tool/CI/derived-package identities, all setup failures and read-only observations. This is not installed RustUSB, GUI or USB I/O acceptance. Private images, disks, firmware variables, keys, signed capabilities, ZIP/deb/ELF bytes are excluded. Every public archive member is hash/size checked; exact private key/capability bytes are checked absent.
