Native ordinary-user console for a provisioned RustUSB agent

Usage: rustusb-gui [OPTIONS] --manifest <MANIFEST>

Options:
      --manifest <MANIFEST>
          Protected public agent manifest; does not contain private TLS keys
      --settings-directory <SETTINGS_DIRECTORY>
          Checked user preferences directory (not an agent configuration)
  -h, --help
          Print help
  -V, --version
          Print version
