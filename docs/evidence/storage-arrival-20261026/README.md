# Storage arrival mechanism evidence

See the [validation report](../../research/storage-arrival-quarantine-validation.md). This archive contains original research (with upstream license files), product-free guest preparation, software checks, all nine mechanism trials, actual terminal observations, fixture revisions and a later read-only audit. Six trials pass; three fail. Two failed clients require separately recorded forced QMP disposal, which is not clean shutdown despite process exit0.

`manifest.json` hashes every archive member. Nested guest archives contain original command/state records. No private key, disk, package or executable payload is included. Upstream GPL sources are research evidence, not RustUSB product implementation. Two failed audit attempts and the corrected method are retained separately; original trial results are unchanged.
